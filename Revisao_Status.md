## 7. O que observar durante os testes?

Durante cada ação, respondam às seguintes perguntas:

1. O sistema informou que recebeu minha ação?
2. Consigo identificar o que está acontecendo?
3. Sei se a operação foi concluída, está em andamento ou apresentou algum erro?
4. O sistema fornece informações suficientes para que eu saiba o que fazer em seguida?

## 8. Entrega da Atividade

Cada aluno ou grupo deverá identificar **pelo menos 8 problemas de usabilidade** relacionados à primeira heurística de Nielsen.

Para cada problema encontrado, registre:

| Item | Descrição |
|---|---|
| **Tela ou funcionalidade** | Onde o problema aconteceu? |
| **Ação realizada** | O que vocês estavam tentando fazer? |
| **Problema identificado** | Qual informação o sistema deixou de apresentar? |
| **Solução proposta** | Como a interface poderia ser melhorada? |

### Modelo de Registro dos Problemas

| Nº | Tela/Funcionalidade | Ação realizada | Problema identificado | Solução proposta |
|---|---|---|---|---|
| 1 |Carrinho |	Cliquei em adicionar um produto ao carrinho. | Nao apareceu nenhuma mensagem confirmando que o produto foi adicionado. | Mostrar uma mensagem de confirmacao e atualizar o contador do carrinho. |
| 2 | Favoritos |Cliquei no coracao de um produto. |Nao houve nenhuma mudanca visual indicando que o produto foi favoritado. |Alterar a cor do coracao quando o produto for favoritado. |
| 3 |Cadastro |Preenchi os dados e criei uma conta. |Nao apareceu nenhuma confirmacao de que a conta foi criada. |Mostrar uma mensagem de cadastro realizado com sucesso. |
| 4 |Login |Tentei entrar com uma senha incorreta. |O sistema nao informou que a senha estava incorreta. |Mostrar uma mensagem de erro informando que os dados estao incorretos. |
| 5 |Login |Entrei com os dados corretos. |A janela fechou sem informar que o login foi realizado com sucesso. |Mostrar uma mensagem de boas vindas. |
| 6 |Carrinho |Aumentei ou diminui a quantidade de um produto. |A quantidade e o valor total nao foram atualizados imediatamente. |Atualizar os valores automaticamente apos cada alteracao. |
| 7 |Checkout |Preenchi o endereco de entrega e cliquei em continuar. |O sistema avancou sem confirmar que os dados foram registrados. |Mostrar uma confirmacao dos dados de entrega. |
| 8 |Finalizacao da compra |Cliquei em confirmar pedido. |A compra foi registrada, mas nao apareceu nenhuma confirmacao de conclusao. |Mostrar uma tela informando que o pedido foi realizado com sucesso. |

## 9. Orientações Importantes

**Atenção:** Não basta escrever que determinada funcionalidade não funcionou. É necessário explicar qual informação está faltando e como o sistema deveria comunicar seu estado ao usuário.

### Desafio Final

O site possui problemas intencionais de usabilidade. Vocês deverão descobri-los sem receber dicas sobre onde estão.

O objetivo não é apenas identificar falhas, mas também **propor soluções que tornem a experiência do usuário mais clara, intuitiva e confiável.**
